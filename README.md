# a-day-of-one-line-pitches

One sentence, 185 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun — for make.fun's "A Day of One-Line Pitches" bounty. The program writes the sentence to `/output/entry.txt`.

> You have never coded and never need to: just describe your app idea in plain words and an AI agent on make.fun builds it into a working app today, free to try, and the idea stays yours.
